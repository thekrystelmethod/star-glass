reaching the engine… how to connect

This page is a client of the ephemeris engine — a small local API that performs all chart mathematics (this page never calculates anything itself). Point it at a running engine:

  1. Install the engine's dependencies (once, from the project folder):
    pip install -r api/requirements.txt
  2. Start the engine in a terminal, from the project folder, and leave it running:
    uvicorn api.main:app --port 8000
  3. Connect. The dot turns green when the engine answers /health. While it's red, this page retries on its own every few seconds. To point at another machine or port, change the address above — or open the page as index.html?api=http://host:port.
